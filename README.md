# Toolkit

A single-file, offline CBT-style self-help toolkit. No build step, no backend,
no analytics, no dependencies beyond a webfont. Open `index.html` and it works.

## What's in it

**Tools** — guided breathing (three patterns), 5-4-3-2-1 grounding, a focus
timer with presets, a "smallest next step" unsticker, and a facts-vs-feelings
thought record with saved history and recurring-word detection.

**Frameworks** — the wrong-couch test, scaffolding-vs-real-work diagnostics, a
tickable fear ladder, boundaries-vs-scorekeeping, and a transition playbook with
week-by-week predictions and counter-moves.

**Tracking** — daily mood check-ins with tags, a streak counter, a 30-day
sparkline, a 24-hour usage histogram, mood-to-page correlation, and a
doing-vs-reading ratio. Everything is stored in `localStorage` on your own
device and never leaves the browser. There is a JSON export.

## Getting around

`⌘K` or `/` opens a command palette over every page, quote and prompt.
`1`–`6` pick a starting point from the home screen. `?` shows the shortcuts.
Pages are hash-routed, so browser back/forward and bookmarks work.

## Privacy

All state lives in `localStorage`. Nothing is transmitted. Clearing site data
clears everything; use the export button first if you want a copy.

## Notes

This began as a personal project and was generalized for sharing. The framing is
second-person throughout because that's how it was written — treat it as a
template to adapt rather than advice. It is not a substitute for therapy.
